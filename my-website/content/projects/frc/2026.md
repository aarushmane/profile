Medusa was Team 2590's 2026 REBUILT robot. I led software development and strategy. The team won the Innovation in Control Award sponsored by nVent at the 2026 FMA Robbinsville District Event. The competition code is not public under FIRST guidelines, so this page describes my documented work rather than a public code walkthrough.

## Technical implementation

- **3D localization:** Architected an Oculus Quest coprocessor pipeline for real-time robot pose tracking. Designed the interface that brought external 3D estimates into the navigation state.
- **Computer vision & pose tracking:** Implemented 3D pose tracking algorithms in Java and OpenCV to estimate robot geometry, field position, and heading.
- **Autonomous execution:** Built Java trajectory wrappers that parsed JSON motion profiles and translated them into command-based actions. Synchronized subsystem scheduling to prevent lag during high-speed movement.
- **Control integration:** Connected localization estimates, trajectory execution, drivetrain behavior, and subsystem commands with explicit timing and state transitions.
- **Scouting intelligence:** Developed Argus with Python API scrapers, MiniMax LLM tooling, Nanobot, and GitHub workflows. Argus sent scouting data, match logs, and graphics to analytical sheets.
- **Engineering leadership:** Led technical strategy across 65 members, reviewed architecture and pull requests, mentored 10+ developers, and connected telemetry to match decisions.
- **Publication status:** The 2026 competition code is not public under FIRST guidelines. This page describes my documented work and its architecture.

## Awards

- **Innovation in Control Award (2026 FMA Robbinsville District Event):** Team 2590 was recognized for the integrated Oculus Quest navigation system, cloud debugging chatbot, and scouting analytics that improved autonomous performance and strategic decision-making.
